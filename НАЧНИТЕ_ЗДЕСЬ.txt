ЛАБОРАТОРНАЯ РАБОТА № 4 — ГОТОВЫЙ ПРОЕКТ

1. Распакуйте архив целиком в обычную папку.
2. Откройте папку lab4_git_branches в проводнике.
3. Внутри есть README.md, файлы задания и ОТЧЁТ.md.
4. История Git уже создана и сохранена в скрытой папке .git.
5. Чтобы посмотреть историю, откройте терминал в этой папке и выполните:
   git log --oneline --graph
6. Чтобы проверить состояние:
   git status

Важно: для просмотра файлов код писать не нужно. Для просмотра истории Git нужен установленный Git.
